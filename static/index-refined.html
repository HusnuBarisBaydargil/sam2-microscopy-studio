Help & Shortcuts

Basic Workflow

  1. Load Image: Use the "Load Image" button to open a valid image file (`.tif`, `.jpg`, etc.).
  2. Annotation folder: Open folder grants access to save beside source images. The server folder setting is only for importing older annotations.
  3. Classes: New projects start without classes. Add a class manually or import annotations with class labels.
  4. Annotation source: Use the server folder path, or load local annotation files/folders to match against the opened images in the browser.
  5. Generate SAM2 candidates: Click this to run or re-run the AI model on the server. Re-runs replace current candidates and can keep existing annotations.
  6. Advanced SAM: Use presets or custom values only when the default SAM behavior is not suitable for the image size or object type.
  7. Classify candidates: Click one or more candidate boxes, create a class if needed, then use Apply class to selection. Enable one-click accept to convert clicked candidates immediately with the active class.

Manual Annotation

For objects the AI missed, click the "Manual Box" button to enter drawing mode. Click and drag on the image to draw a new box. When you release the mouse, a menu will appear to classify or cancel it.

Editing Annotations

  • Move: Select a box, then drag inside it.
  • Resize: Select a box, then drag one of its white handles.
  • Precise edit: Use the Selected Box fields for exact x/y/w/h values.
  • Nudge: Select boxes and use arrow keys. Hold Shift for larger moves.

Segmentation classes

New objects sets the class used for drawing and suggestions. Select an object and use its class button above the canvas to change that object's class. Expand Manage classes to search the class list; use Edit beside a class to change its name, color, or shortcut.

Segmentation drawing

Polygon (1): click vertices and press Enter. Rectangle (2): click opposite corners. Circle (3): click the center, then its edge. Drag a saved shape's handles to adjust it. Right-click a polygon corner to remove it, or focus the corner with Tab and press Delete/Backspace. Polygons need at least three points. Ctrl+Z removes the last draft point or undoes a completed edit or SAM2 run; Escape cancels drawing.

Hold the middle mouse button and drag to pan, including while drawing. Left-drag a point in an unfinished polygon to adjust it. Overlapping points are highlighted as soon as you place or drop them; move a highlighted point to fix it without restarting. Escape during a point drag restores its previous position.

Click-assisted SAM2

Click segment creates a new object. To correct an existing object or suggestion, select it and choose Correct above the canvas. The original boundary is dashed white; the preview is gold. Original toggles the preview for comparison. Use Exclude or right-click to remove unwanted areas. Undo click (Ctrl+Z) removes the last prompt. Apply correction or Accept preview saves one undoable edit; Cancel or Escape discards the preview. Applied image processing is used.

Split and Merge

For Split, select one saved object or suggestion, then click once per cell (2–16 cells). Undo click removes the last seed. For Merge, toggle saved objects in the list, or select suggestions before starting. Choose the output class beside Accept. Both operations show a preview first; acceptance autosaves one undoable edit. Split stays inside the original outline and may exclude background. Merge needs touching or overlapping regions forming one outline without holes; it does not bridge gaps. Boundaries use source-image pixels and up to two-pixel simplification. New objects receive new IDs; Undo restores the original objects.

For a manual split, select a saved polygon and choose Cut line. Pick two boundary anchors, optionally add points to bend the cut, then Apply split. The cut must stay inside the original outline. Both pieces retain the parent's class and exact outer boundary, receive new IDs, and autosave as one undoable edit. Ctrl+Z removes draft points or undoes an applied split; Escape cancels. Middle-mouse panning remains available.

Segmentation view

Use View to show or hide saved objects, suggestions, numbers, and fills, or fit the image. Alt-click repeatedly to cycle through overlapping objects; suggestions toggle selection as you cycle. Hiding suggestions clears their selection. These controls do not change saved annotations.

Segmentation suggestions

Suggest generates temporary outlines. Click a cell or its numbered badge to select it; click again to deselect. Gold marks selected suggestions, and white marks the hovered suggestion. Choose the class beside Accept above the image to save all selected objects to that class. Reject removes selected suggestions; Deselect clears only the selection. Clear suggestions removes all pending suggestions and keeps saved objects. Undo restores the last batch.

Suggestions are temporary until accepted. Running SAM2 again replaces pending suggestions. Check overlapping selections for unwanted whole-cluster outlines.

Masks with holes, disconnected pieces or invalid outlines are skipped. Polygon boundaries are simplified with a tolerance of at most 2 image pixels.

Canvas Controls

  • Pan: Click and drag the image background.
  • Zoom: Use your mouse wheel or the + / - buttons in the bottom-right corner.
  • Reset View: Click the Fit button to fit the entire image in the view.

Keyboard Shortcuts

  • B: Toggle Manual Box mode.
  • Class hotkeys: Configure each class shortcut in the Classes panel.
  • U or Ctrl+Z: Undo the last annotation edit.
  • Ctrl+Y or Ctrl+Shift+Z: Redo the last undone annotation edit.
  • Delete: Delete the selected annotations as one reversible edit.
  • Import current image: Import an existing CSV, YOLO TXT, COCO JSON, or Pascal VOC XML file for the loaded image.
  • Import Matched: Import all matched annotation files for the opened image folder. Ambiguous duplicate image names are skipped until path-specific annotation files exist.
  • Save current annotations: Annotations autosave beside each image after opening its folder with write access. Save retries a failed write.
  • Validate project: Check all loaded images, classes, and final annotations for COCO dataset consistency.
  • Export project COCO: Validate and download one consolidated COCO file for every loaded image, requiring reviewed images and explicitly confirmed empty negatives.
  • Escape: Exit Manual Mode, cancel a drawing, or close this window.
